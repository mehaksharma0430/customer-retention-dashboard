About the data

Online Retail II from the UCI Machine Learning Repository: every invoice line from a UK-based online gift retailer between 1 Dec 2009 and 9 Dec 2011. Many customers are wholesalers. Each row is one product on one invoice. The dataset has no membership field and no order-frequency field, so both were derived from the transactions. Source page

From raw rows to valid sales

Missing values in the raw data

Price of 0 or less (6,207 rows) was treated as a missing order value and excluded. Order frequency is undefined for customers with a single order, so it is filled with the training-set median.

Columns and derived features

Membership levels

Derived from lifetime spend before the cut-off, split at the spend quartiles.
